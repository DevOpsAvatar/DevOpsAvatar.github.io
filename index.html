  1. Nov 2026 Shipped

    Launch a Kubernetes cluster on Amazon EKS

    I launched an EKS cluster with eksctl from an EC2 instance, tracked the build in CloudFormation, and gave myself access with an IAM access entry. Two IAM permission errors along the way taught me how eksctl, IAM roles and node groups fit together. When I deleted the worker nodes, the node group replaced them on its own. I deleted all the resources the same day to avoid charges.

    Amazon EKS, eksctl, CloudFormation, IAM, EC2, kubectl

  2. Nov 2026 Shipped

    Build a Kubernetes controller

    I built a custom controller that keeps an EchoServer resource at its desired state. When I scaled the Deployment down by hand with kubectl, the controller noticed the drift and scaled it back to 3 replicas. I also made it report its status back to the API server. The hardest part was debugging a Go version mismatch and SchemeBuilder registration errors.

    Kubebuilder, Go, kind, kubectl, CRDs, reconciliation loops
