  1. Deploy a backend with Kubernetes

    Nov 2026

    I deployed my Flask backend to an EKS cluster by applying a Deployment and a Service manifest with kubectl. In the EKS console I followed a pod's events from scheduling, to pulling the image from Amazon ECR, to starting the container, which confirmed the cluster could authenticate with ECR and run the app without errors. I deleted the cluster, nodes and ECR repository afterwards to avoid charges.

  2. Create Kubernetes manifests

    Nov 2026

    I wrote the Deployment and Service manifests that run my Flask backend on EKS. The Deployment pulls the Docker image from Amazon ECR and keeps the pods running, and a NodePort Service routes traffic on port 8080 to them by label. Annotating the Deployment section by section taught me what spec, selector and template do. Next I want to learn rolling updates and liveness and readiness probes.

    • Kubernetes manifests
    • Deployments
    • Services
    • Amazon EKS
    • ECR
    • Docker
    Read the write-up for Create Kubernetes manifests

  3. Set up a Kubernetes deployment on EKS

    Nov 2026

    I created a three-node EKS cluster with eksctl, cloned a Flask backend, built its Docker image and pushed it to Amazon ECR so the cluster can pull it. A Docker permissions error taught me how the docker group controls access to the Docker daemon, and the hardest part was troubleshooting a terminal that hung while waiting on CloudFormation.

    Read the write-up for Set up a Kubernetes deployment on EKS

  4. Launch a Kubernetes cluster on Amazon EKS

    Nov 2026

    I launched an EKS cluster with eksctl from an EC2 instance, tracked the build in CloudFormation, and gave myself access with an IAM access entry. Two IAM permission errors along the way taught me how eksctl, IAM roles and node groups fit together. When I deleted the worker nodes, the node group replaced them on its own. I deleted all the resources the same day to avoid charges.

  5. Host a website on Amazon S3

    Nov 2026

    My first AWS project. I created a bucket in the Stockholm Region, uploaded a website's HTML and images, and turned on static website hosting. The site first returned a 403 Forbidden error because the files were private, and I fixed it by making the ACL public.
